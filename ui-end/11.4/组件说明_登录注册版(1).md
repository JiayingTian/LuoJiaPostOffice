# 组件说明 · 登录 / 注册页（luojia-auth）

> 本页是「珞珈烟火邮局」的 **登录 / 注册** 页面，仿小红书校园门户那种「萌角色眼睛跟随鼠标 + 输密码转头不看」的交互，套进左插画 / 右表单的分栏布局。视觉与站内其余页面（奶油米纸底、金棕点缀、楷体标题、校园剪影页脚）完全一致。
>
> 交付给前端的三件套：`luojia-auth.src.html`（结构 + 交互 JS，CSS 外链、图片相对路径）+ `luojia-auth.css`（全部样式）+ 本说明。`luojia-auth.html` 是自包含预览版（CSS + 图片全 base64 内联），可本地预览或直接用 Figma 的 html.to.design 导入。

## 3. 萌角色（小信使）组件

四个角色都套同一套 `.mascot` 结构，仅用修饰 class 区分外观：

| 角色 | class | 特征装饰 |
|------|-------|----------|
| 邮箱小邮差 | `.m-post` | 头顶 `.slot`（投递口）+ 侧面 `.flag`（金旗） |
| 信封宝宝 | `.m-env` | 右上 `.stamp`（邮票） |
| 蓝帽猫（呼应 Katrina） | `.m-cat` | 两只 `.ear`（耳朵） |
| 抱月刺猬（呼应 Pie） | `.m-hedge` | 三个 `.spike`（刺） |

每个 `.mascot` 内部结构（**务必保持一致，眼睛跟随 JS 依赖此结构**）：

```html
<div class="mascot m-post">
  <span class="slot"></span><span class="flag"></span>   <!-- 角色专属装饰，非必须 -->
  <div class="face">                                     <!-- 正面（含五官） -->
    <span class="eye l"><span class="pupil"></span></span>
    <span class="eye r"><span class="pupil"></span></span>
    <span class="blush l"></span><span class="blush r"></span>
    <span class="mouth"></span>
  </div>
  <span class="back"></span>                             <!-- 背面（转身后显示的"后脑勺/邮戳"） -->
</div>
```

**关键 class**（转框架时一一对应）：

| class | 说明 |
|-------|------|
| `.mascot` | 单个角色容器；`transform-style:preserve-3d` + `transition`，转身动画挂这里 |
| `.mascot .face` / `.back` | 正面 / 背面；都设 `backface-visibility:hidden` |
| `.mascot .eye` `.eye.l` `.eye.r` | 左右眼（白底圆，overflow:hidden），定位靠 `left/right:24%` |
| `.mascot .pupil` | 瞳孔，**JS 每帧改它的 `translate` 实现眼睛跟随** |
| `.mascot .blush` `.mouth` | 腮红 + 嘴（纯装饰） |
| `.m-post` … `.m-hedge` | 用 `--mc` 改每个角色的脸底色 |
| `.auth-art.shy .mascot` | 触发 `rotateY(180deg)` → 整体转过身去（背对） |

| 提示 | `.fld .hint` | `.hint b` 金色重点；`.hint.err` 红色（备用） |

| 行内选项 | `.row-opt` | 记住我（checkbox）+ 忘记密码（登录面板） |
| 主按钮 | `.btn-gold` | 金棕渐变，全宽 |
| 切换提示 | `.switch-tip` | 「还没有账号？免费注册 →」 |

### 字段约束（产品硬性要求）

- **用户名**：只允许 **小写字母 a–z**。JS 在 `input` 事件里 `value.toLowerCase().replace(/[^a-z]/g,'')` 实时过滤，出现非法字符时输入框加 `.invalid` 并弹 toast「用户名只能用小写字母 a–z」。
- **密码**：支持 **大小写字母、数字、特殊字符**（如 @ # _ . !）。注册页带 4 段强度条；登录 / 注册密码框都有显示 / 隐藏切换。
- **注册字段**：用户名 + 密码 + 确认密码（**无邮箱**，按需求已删除）。

> ⚠️ 邮箱字段（`re-mail` / `name="email"`）已从结构、JS 校验、提交逻辑三处彻底移除，前端若看到旧稿里有"邮箱"请忽略。

## 5. 交互逻辑（JS，见 `luojia-auth.src.html` 内 `<script>`）

全部包在 IIFE 里，纯原生 JS，无依赖。

### 5.1 萌角色状态机
状态由两个条件决定，集中在 `refreshMascot()`：

| 条件 | 状态 `mode` | 小信使表现 | 心情气泡 |
|------|-----------|-----------|----------|
| 焦点在用户名框 | `peek` | 探头「👀 偷看中…你打字好认真」（仅上浮 6px） | 偷看台词 |
| 有密码处于**明文** | `shy` | **整只转过身去背对你**（rotateY 180）+ 气泡「🙈 哎呀呀，密码不许看^_^」 | 害羞台词 |
| 其余（隐藏密码 / 空闲） | `idle` | 眼睛**全向自由跟随鼠标** | 默认台词 |

- **眼睛跟随**：`mousemove` 记录鼠标坐标，`requestAnimationFrame(draw)` 每帧算每个瞳孔相对鼠标的偏移（`MAXR=5` 限制幅度），写入 `.pupil` 的 `translate`。**空闲与偷看都全向跟随**，只有 `shy` 时眼睛被转身遮挡看不见。
- **眨眼**：`blinkLoop` 随机给某个瞳孔 `scaleY(0.12)` 130ms。
- **触发区分（重要）**：
  - 输入**焦点**只切换「偷看 / 不偷看」→ 点输入框本身**不**触发转身；
  - **只有点「显示 / 隐藏密码」按钮**才触发 `passwordShown`，进而切换「转过去不看 / 恢复自由看」。

### 5.2 显示 / 隐藏密码
点击 `.toggle[data-toggle]`：切换对应 `input.type = password/text` + `dataset.show`，按钮文案 👁↔🙈，并调用 `refreshMascot()`。**这是唯一改变"看 / 不看"的入口。**

### 5.3 用户名小写过滤
见 §4 约束。

### 5.4 密码强度（注册）
`rePass` 的 `input` 事件按 小写 / 大写 / 数字 / 特殊 四类累加 `score`，给 4 个 `<i>` 加 `on1..on4`。

### 5.5 标签 / 面板切换
`switchForm(name)` 切 `.view-tab.is-active` + `panel.hidden`。**切换时重置** `focusedField=null; passwordShown=false`，并把两个面板的密码框与 toggle 复位为隐藏态。

### 5.6 提交（演示）
`formLogin` / `formRegister` 的 `submit` 阻止默认，做前端校验（用户名非空、密码≥8、两次一致），弹 toast 演示文案。**未接后端**，后端接口由前端接。

## 8. 转 React / Vue 建议

- **状态**：用一个 `mode`（`idle|peek|shy`）+ `activeForm`（`login|register`）+ `pwShown`（或按字段分别记）+ `username` 等受控值即可对应全部交互。
- **萌角色眼睛**：把 `draw()` 的 rAF 循环搬进 `useEffect`/`onMounted`，瞳孔偏移用 `transform` 内联样式，鼠标监听在卸载时移除。
- **转身**：`authArt` 容器加 `shy` class 即可，CSS 已写好 `rotateY(180deg)` 动画，无需额外 JS。
- **用户名过滤**：受控 `onChange` 里 `setValue(v.toLowerCase().replace(/[^a-z]/g,''))` 即可。
- **组件拆分参考**：`<AuthHeader/>`、`<MascotArt mode=.../>`、`<AuthCard form=.../>`（内含 `<LoginForm/>` `<RegisterForm/>`）、`<SiteFooter/>`。
