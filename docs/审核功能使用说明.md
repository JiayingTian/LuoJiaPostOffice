# 珞珈烟火邮局 · 信件审核功能使用说明

> 本文仅适用于运行 `npm run dev:api` 的真实 FastAPI 后端。当前 GitHub Pages 和 `npm run dev` 的演示版没有管理员审核步骤，公开信寄出后直接进入公共来信。真实 API 的审核逻辑仍保留，以下测试步骤不是当前网页演示的操作流程。

## 1. 功能范围

1. 只有公开信件进入审核队列。
2. 私密信件不审核，且只有作者和指定收件人可读。
3. 只有后端确认 `role=admin` 的账号可以查看和处理审核队列。
4. 审核记录保存在 `moderation_records`，前端不能自行修改审核状态。

## 2. 启动与账号

1. 启动 FastAPI：

   ```powershell
   conda activate postoffice
   cd D:\Code\26LingCup\backend
   python -m uvicorn app.main:app --reload --port 8000
   ```

2. 另开终端启动前端与代理：

   ```powershell
   cd D:\Code\26LingCup
   npm run dev:api
   ```

3. 如需重置测试账号：

   ```powershell
   cd D:\Code\26LingCup\backend
   python -m scripts.create_test_accounts
   ```

4. 脚本会输出 `test_user_a`、`test_user_b`、`test_admin` 的临时密码；密码不要提交到 Git。

## 3. 页面操作

1. 使用普通用户登录 `http://127.0.0.1:4173/frontend/`。
2. 写一封公开信并确认寄出；该信进入“待审核”。
3. 退出普通用户，使用 `test_admin` 登录。
4. 点击页头“审核”，打开待审核列表。
5. 点击信件查看全文，然后选择：

   - “审核通过”：信件进入公共来信。
   - “退回草稿箱”：必须先选择一个原因标签。

6. 允许的退回原因只有：

   - 色情低俗
   - 暴力血腥
   - 仇恨歧视与骚扰
   - 违法违规内容
   - 垃圾信息与恶意广告

## 4. 退回后的作者体验

1. 信件从审核队列移除并回到作者草稿箱。
2. 作者在详情页看到“未通过原因”。
3. 作者修改后可以再次提交审核。
4. 旧的审核记录保留，不覆盖历史。

## 5. 接口约定

1. 获取待审核列表：`GET /api/v1/admin/letters`。
2. 审核通过：

   ```json
   { "action": "approve" }
   ```

3. 退回修改：

   ```json
   { "action": "returnForEdit", "reason": "垃圾信息与恶意广告" }
   ```

4. 审核接口：`POST /api/v1/admin/letters/{letterId}/review`。
5. 重复处理同一版本返回 `409`。
6. 普通用户访问管理员接口返回 `403`。

## 6. 验收清单

1. 普通用户提交后只能看到“待审核”，公共信箱看不到正文。
2. 管理员能在审核列表打开全文。
3. 通过后，游客能在公共信箱查看信件。
4. 未选择原因时，前端不能执行退回。
5. 退回后，作者能看到原因并继续编辑。
6. 私密信件始终不出现在审核列表和公共信箱。
