# 珞珈烟火邮局 · 前端说明

当前页面入口为仓库根目录 `index.html`（首页）、本目录 `index.html`（公共来信、我的信件、写信与读信）、`about.html`（关于我们）、`auth.html`（登录与注册）。素材位于 `assets/`。

## 展示流程

公共来信支持按页浏览、读信和“偶遇一封信”；时光日历可以按日期查看来信。登录演示后可写信，依次填写标题和正文、挑选信纸和邮票、设置公开或私密、预览并寄出。投递动画完成后提供“查看信件”。演示模式中的公开信直接显示在公共来信，私密信只进入个人列表。作者可在详情中编辑或确认删除自己的已寄信，编辑打开带有原内容的写信页；保存草稿会使已公开的原信从公共列表退出。也可在“我的信件”中查看草稿、回信、已公开与已私密信件。

## 两种运行模式

- `npm run dev` 和 GitHub Pages 使用 `demo`。演示账号和信件保存在当前浏览器，不具备跨用户、跨设备共享能力，也不调用真实审核接口。演示版的寄出动画结束即进入投递完成。
- `npm run dev:api` 使用 `api`，请求代理到本机 FastAPI。当前后端保留管理员审核规则：公开信及公开回信提交后等待管理员通过，之后才在公共来信可见。真实账号、权限、CSRF、私密收件人和数据库持久化需在这套模式下验证。前端页面尚未把真实模式的审核流程调整为演示模式的即时公开流程。

本地联调需要 Node.js 20+、数据库和后端服务。按 [后端 README](../backend/README.md) 配置数据库并启动 `python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000`，在仓库根目录运行 `npm run dev:api`，打开 `http://127.0.0.1:4173/`。开发代理会将 `/api/v1` 转发到 `http://127.0.0.1:8000`。环境变量 `FRONTEND_MODE` 可设为 `demo` 或 `api`，`BACKEND_ORIGIN` 可设置后端地址。

## 文件与验收

`app.js`、`app.css` 是分离的信件应用代码；正式 `index.html` 同步保留内联实现。`demo.js` 是演示数据服务，`api.js` 是真实接口客户端，`domain.js` 是校验与请求映射，`calendar.js` 整理日历数据。`config.js` 默认静态演示配置，`auth.js` 处理真实登录页，`calendar-v21.css` 补充日历样式。修改信件功能时应同步检查分离代码和页面内联实现。

提交前检查首页、公共来信、写信、寄出、读信、我的信件、编辑／删除和日历在指定宽度及慢网条件下的实际表现。运行 `npm test` 时目前有一条旧的状态文案测试期待“待审核”，与前端的“已投递”标签不一致；这条测试不能算作通过。后端管理员审核验收步骤见 [审核说明](../docs/审核功能使用说明.md)。
