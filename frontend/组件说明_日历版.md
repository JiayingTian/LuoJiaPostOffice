# 珞珈烟火邮局 · 时光信笺（日历检索版）组件说明

> **历史资料**：本文记录早期设计或接口约定，不是当前参赛演示的操作说明。当前 GitHub Pages 与 `npm run dev` 使用演示模式，公开信寄出后直接展示；`npm run dev:api` 接入的真实后端仍保留管理员审核。请以仓库根目录 README 和当前源码为准。

> 给前端（Katrina-）转代码用的对照表。
> 本页是「时光信笺」的交互版本，含 **日历检索**（仿微信/QQ 按日期查聊天记录：日历标记有信日期，点日期列出当天信件）与 **时间轴**（按时间倒序流览全部信件）双视图，可在卡片顶部切换。

## 四、交互逻辑（原生 JS，转框架时对应成状态/方法）

数据模型：信件是一个数组，每条含 `{y, m, d, t(时分), title, preview}`。

```js
var letters = [ /* y/m/d/t/title/preview … */ ];

// 1) 按 "年-月-日" 建立索引，支持同一天多封信
var map = {};
letters.forEach(function(l){ var k = l.y+"-"+l.m+"-"+l.d; (map[k]=map[k]||[]).push(l); });

// 2) 视图状态：当前查看的月份(viewY/viewM)、选中的日期(selected)、应用“今天”(TODAY)
// 3) renderCalendar()  渲染当月网格：补位空格 + 1..days，给有信/今天/选中加 class，绑定点击
// 4) selectDate(y,m,d) 设置 selected → 重渲染日历 + 调 renderResult()
// 5) renderResult()    按 selected 取 map[k]；无则显示 .cal-empty，有则渲染 .tl-card 列表
// 6) 上月/下月按钮：viewM 加减并跨年修正，仅重渲染日历（不丢 selected）
// 7) renderTimeline()  把 letters 按时间倒序(新→旧)排序，渲染竖轴时间轴 .tl-node（金点 + .tl-card）
// 8) 视图切换：点击 .view-tab 切 data-view；calendar/timeline 两个面板用 hidden 互斥显示，并切换 .is-active
```

**要点**
- 默认 `selected = TODAY = {2026,11,2}`，打开即停在 11 月并选中当天（演示同日多信）。
- 点击任意日期都会触发结果渲染；当天无信 → 友好空态，不报错（对应微信"当天无消息"）。
- 日历网格用 `Date(viewY, viewM-1, 1).getDay()` 算星期起点，`new Date(viewY, viewM, 0).getDate()` 算当月天数。
- 示例数据 10 封，分布在 1/3/5/6/7/8/9/10/11 月，翻月时不同月份都有金点，检索效果直观。
- 双视图：状态二顶部「日历 / 时间轴」切换。日历视图=左日历+右结果两栏（检索）；时间轴视图=全部信件按时间倒序的竖向时间轴（流览）。两个面板 `hidden` 互斥，互不干扰。

## 五、响应式

```css
@media(max-width:860px){
  .header nav{ gap:16px; font-size:14px }
  .tl-card{ flex-direction:column; gap:12px }   /* 信件卡转竖向 */
  .tl-env{ flex:0 0 auto; width:54px }
  .orn-wensu{ display:none }                     /* 窄屏去掉右侧文素装饰 */
  .cal-content{ grid-template-columns:1fr }       /* 两栏回退为上下单栏 */
  .cal-col-left{ padding:0 0 22px }
  .cal-col-right{ padding:22px 0 0; border-left:none; border-top:1px dashed var(--line) }  /* 结果回到顶部虚线分隔 */
}
```
日历本身 7 列网格自适应收缩，无需额外断点；两栏布局在窄屏自动堆叠为上下单栏。

## 六、转代码建议（React / Vue）

1. 引入 `luojia-calendar.css`（已含全部样式，含公共外壳与日历专属）。
2. 拆组件：`Calendar`（月视图网格 + 上下月）、`CalendarCell`、`LetterCard`、空状态 `EmptyState`。
3. 状态：`viewMonth`（{y,m}）、`selectedDate`（{y,m,d} | null）、`letters`（数组，来自接口）。
4. 渲染：`selectedDate` 对应的信件用 `letters.filter(...)` 算出；无则显示「这一天还没有留下信笺」。
5. 真实接入时，`letters` 改为按日期从后端拉取；日历上的金点由"该日是否有信"决定（可先请求"每月有信日期集合"做标记，点日期再拉明细）。
6. 资源：装饰图与信封走静态目录；纸纹/剪影按原路径引用即可。
